# 接手这份讲座前先读这里

《做中学与综合实践活动——AI 在任务链条上的位置》。主讲辛海洋，面向深圳综合实践活动教师，
90 分钟纯讲，正文 46 页，另附录 25 页不讲。共 71 页。

听众画像决定了这份材料的一切取舍：**综合实践活动教师，小学与初中混合，多数不是科学教师，
AI 使用经验很弱。** 判断任何改动好不好，只问一句：技术基础弱的老师看完这一页，能不能照着做。

## 一、动手之前必须知道的五条

1. **`slides.data.js` 是页面内容与讲稿的唯一真源。** 网页版和 pptx 都从它生成，不要在两边分别改。
2. **`palette.js` 是色值的唯一真源。** styles.css 的 `:root` 由 `node palette.js` 生成，
   figures.js 与 build_pptx.js 直接 require 它。三处曾各写一份，撞过车，不要退回去。
3. **`OUTLINE.md` 里被 `<!-- gen:xxx -->` 包住的段落是生成的**，手改会被 `node gen_outline.js` 覆盖。
   `slides.data.js` 里的分段横幅注释同样由它重写。
4. **事实纪律**：政策条款、文号、日期、数字、论文标题一律不得新增或改写。
   现有的全部来自交接文档的事实清单与《做中学领航行动指南》附件原文（逐字照录）。
   查不到就删，不要补一个看起来合理的。
5. **语体**：平实论说文。禁用词「赋能、抓手、闭环、生态、底座」；不用设问、不用戏剧腔、
   不堆「不是…而是」（全场配额一次，已用在第 7 页本场主张）、不写升华尾巴、不给构念加粗。
   全角中文标点。

## 二、改完必须跑的检查

```bash
# 内容改动
node build_pptx.js 做中学与综合实践活动.pptx     # 重新生成 pptx
node build_pptx.js --60 做中学与综合实践活动-60分钟版.pptx
node gen_outline.js                              # 重写 OUTLINE.md 的生成段与数据文件的横幅

# 讲义
node build_handout.js 教师讲义.html
# NODE_PATH 指向含 playwright 的 Node 依赖目录后执行
node print_handout.js 教师讲义.html 做中学与综合实践活动-教师讲义.pdf

# 配色改动
node palette.js        # 重写 styles.css 的 :root
node check_colors.js   # 对比度与色差实测，不手写数字
python3 make_figures.py 8795   # 图示重新栅格化（需仓库根目录起静态服务）

# 版式改动
node check_css.js      # 类名撞车与孤儿类
```

逐页转图检查是必须的，两个版本都要。这个仓库里没有现成脚本（在会话的临时目录里），
接手时请自行写一个：网页版用 Playwright 截 71 页并检查 `scrollHeight > clientHeight`
**以及每个子元素**（`overflow:hidden` 的容器内部被裁掉的内容，页级检查看不见，
附录六张表就是这么漏过去的）；pptx 用 python-pptx 读几何自绘预览并报越界。
环境里 LibreOffice 不可用。

## 三、结构

| 文件 | 作用 |
| --- | --- |
| `slides.data.js` | 71 页的内容与讲稿。唯一真源 |
| `palette.js` | 色值唯一真源，可执行（重写 styles.css 的 :root） |
| `figures.js` | 7 张 SVG 图示，网页内联，pptx 走栅格化的 PNG |
| `make_figures.py` | 在讲座页面的浏览器上下文里把 SVG 栅格化，字体与网页版一致 |
| `app.js` | 网页版渲染器，按 `layout` 字段分派 |
| `build_pptx.js` | pptx 生成器，同一套 `layout` 各写一份几何 |
| `styles.css` | 版式。`:root` 段是生成的 |
| `gen_outline.js` | 重写 OUTLINE.md 的生成段与数据文件的分段横幅 |
| `check_colors.js` / `check_css.js` | 配色核验 / 类名核验 |
| `OUTLINE.md` | 逐页大纲、各段时长、档位、图示页码 |
| `占位与待确认清单.md` | 六次改版的记录、替 Tony 做的决定、已处理的风险、待决项 |

**加新版式要改三处**：`slides.data.js` 加数据、`app.js` 加渲染器、`build_pptx.js` 加渲染器，
另加 CSS，再在 `gen_outline.js` 的 `SCREEN` 里登记一行（不登记会抛错）。

**档位**：`tier` 为 `A`（60 分钟版保留，40 页）、`B`（90 分钟专属，6 页）、
`附`（附录 25 页，不讲，不计时长，压缩时也不删）。

## 四、这份材料的立场，不要改掉

- 全场脊柱（第 7 页，仅出现一次）：生成式 AI 并非解决本课程既有问题的工具，而是一个同时
  放大两端的变量。既有的实施问题恰是 AI 最容易加剧的部分；既有的教师负担恰是最容易减轻的部分。
- 判据（第 22 页）：越接近学生必须亲自形成的能力，AI 系统的介入范围越小；越接近准备、整理、
  反馈与教师支持，允许的介入范围越大。
- 六个环节的收放配置是**依据评价维度做的专业判断，不是政策规定**。指南原文只写了「辅助」二字。
  末页第三条明写了这一点，讲述时必须说成建议。这条不可删。
- 责任归属（第 40 页）：提出、确认可以部分借助工具；**否决、评价、负责落在教师签名上**。
  全场只有这一页正面讲，因此是 A 档，压缩时不删。
- 配重：正文中的指导与可操作内容必须多于问题、风险与限制。这个比例是三轮改版调出来的，
  起因是初稿「讲不能给的比讲能怎么用多得多」，会把还没学会的老师吓跑。**不要让它退回去。**

## 五、还没定的事

1. ~~讲义与二维码。~~ 已定：封面右下角放置二维码与可点击入口，指向公开的 37 页教师讲义；
   PowerPoint 封面同步保留二维码和超链接。末页继续说明纸质讲义内容，不再承担下载入口。
2. 字体：网页版大标题用思源宋体，pptx 两处都用微软雅黑（中文 Windows 一定有）。
   三选一未定：嵌入字体、转曲、维持现状。品牌口径规定西文 Inter、中文思源黑体，
   但没规定衬线中文，所以大标题该不该统一也一并待定。
3. 配色用了品牌深蓝（见 `palette.js`）。此前定过「不能体现出商业」，色值不是标识，
   判断为不构成商业信号，但这是 Tony 的场，他可以推翻。
4. 第 7 页本场主张的措辞：现在这版是从口语改写过来的，Tony 原话可能更好。
5. 两处课时提法（第 11 页老问题清单、第 24 页任务卡的建议课时）要不要一并去掉。
6. 附录六张收放配置表是否要守正文的「表格上限两张」纪律。
