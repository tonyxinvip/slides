核心命题

必要性、适度性与可撤除性构成技术介入的三个条件

教师需要判断技术介入是否必要、介入程度是否适当，以及支架能否在目标达成后撤除。

技术介入的判断应以具体教学问题为起点，工具名称与平台功能不构成充分依据。必要性、适度性与可撤除性构成本报告的基本分析框架。 [Sources] 《AI赋能小学科学——人机协同，素养共生》PDF，第2页

课堂问题结构

技术选择应由学习障碍类型与教学目标共同决定

01

现象表征受限

过程尺度、发生速度或观察距离超出学生直接感知范围。

02

探究条件受限

时间、器材、安全与班额约束降低了实验操作和变量比较的可实施性。

03

评价证据不足

课堂活动可见，但学生依据证据修订解释的过程缺乏记录。

现象表征、探究条件与评价证据是既有的教学问题。AI只有在能够对应其中一类问题并改善学习条件时，才构成有意义的教学介入。 [Sources] CODEX_HANDOFF.md：五部分结构 v4 第4页 旧版报告第8—12页

教学基本原则

直接经验、实验操作与证据表达构成不可替代的学习活动

可由真实材料完成的观察与实验应保留；证据不足时不形成确定结论；安全与教学判断由教师负责。

AI系统应承担限定功能，而不应接管完整探究过程。
小学科学学习以直接经验、实验操作和证据表达为基础。后续案例均以AI是否保留这些核心学习活动作为判断标准。 [Sources] CODEX_HANDOFF.md：必须保留的边界 v4 第5、8、42页

数字表征扩展观察条件，概念理解仍需学生解释

日食 · 第二步

交互模拟用于弥补实体模型的尺度限制

2比较本影与半影

植物生长

连续观察记录是植物生长学习的主要证据

高度、叶片与光照记录不能由生成视频替代；具备相应处理能力的系统可辅助整理照片与定位缺失项。

生成视频可以作为时间变化的辅助表征，但不能作为特定植物生长过程的观察证据。照片对齐与缺失识别等结果仍需依据原始记录复核。 [Sources] v4 第15页 旧版报告第17—21页

方法归纳

动画理解需要通过独立解释与情境迁移进行检验

学生应在脱离动画后依据自己的记录完成解释，并在新情境中检验概念迁移。

现象识别与证据解释属于不同层次的学习表现。
对动画内容的识别不能直接证明概念理解。学生能否在没有动画支持时使用实体模型解释日食，构成对独立理解与表征迁移的进一步检验。 [Sources] v4 第17页
02

探究活动的认知责任

完整实验流程不能证明学生承担了探究认知责任

当问题、方案、步骤与结论主要由系统生成时，实验形式的完整性不能证明学生承担了探究思考。

教师备课效率与学生探究质量属于不同评价对象。AI缩短课件制作时间，不等同于增加学生提出问题、比较证据或修订解释的机会。 [Sources] 旧版报告第4页 v4 第18—21页

探究活动的认知投入

实验活动的形式完整性不等同于认知投入

证据驱动的探究

  • 形成或理解研究问题
  • 收集并比较实验数据
  • 依据证据修订解释

程序性活动

  • 执行既定操作步骤
  • 验证预设结论
  • 提交结果性作品

判断重点在于学生是否承担证据比较与解释修订。

教师提供材料与操作支持并不必然降低探究质量。区分两类活动的关键在于，研究问题、证据解释和观念修订是否仍由学生承担。 [Sources] v4 第19页 旧版报告第11、13页

现实约束

时间、器材与班额约束可能降低探究活动的认知投入

01

时间

长周期现象与重复试验受到课时限制。

02

器材与安全

器材数量和安全要求限制部分变量的操作。

03

班额

大班环境增加过程记录、讨论组织与反馈分析的难度。

小学科学探究受到课时、器材、安全与班额等结构性条件限制。AI的潜在价值应通过其是否改善实验可实施性与过程证据处理能力加以判断。 [Sources] v4 第20页 旧版报告第10页

教学价值判断

教学价值应由探究机会增量与独立表现共同检验

01

机会增量

新增可观察、可操作或可比较的学习机会

02

证据增量

形成能够追踪预测、记录与修订的过程材料

03

独立表现

撤除支架后仍能在相近任务中完成关键判断

04

实施代价

核验、设备、数据与课堂组织成本处于可控范围

答案获取速度属于信息效率指标，不能单独证明探究学习质量。

AI介入应增加学生操作、记录、比较或论证的有效机会。若系统仅提高答案获取速度，其作用主要体现为信息效率，尚不足以说明探究学习质量得到改善。 [Sources] v4 第21页

迁移任务

变量迁移用于检验公平比较方法的独立运用

工程概念区分

最大承载量与安全承载量对应不同的工程判断

极限测试

最大承载量

作品发生明显失稳或进水前达到的极限负载

稳定裕度
使用判断

极限值用于认识结构边界，安全值用于形成可执行的使用判断。

最大承载量属于极限测试结果，安全承载量需要进一步考虑稳定性与裕度。小学工程实践可以借此区分追求最高数值和形成安全使用判断两类任务。 [Sources] 《第二章 AI赋能小学科学备课与课堂分析》：最大承载量与安全承载量讨论

支架撤除

AI支架应随学生独立能力的发展逐步撤除

1完整示范2证据提醒3按需追问4独立完成

撤除支架后的问题提出、证据比较与解释修订构成独立表现证据。

支架撤除可以从完整示范逐步过渡到证据提醒、按需追问与独立完成。撤除节奏应依据学生的独立表现调整，不采用固定课时预设。 [Sources] 旧版报告第13—14页 v4 第30页
03

过程性证据与形成性评价

学习进展需要通过解释修订的过程证据加以判断

AI系统可辅助整理课堂片段与学生记录；观念变化的解释仍需由教师依据证据作出。

学习评价不应仅依据结果正确性。将实验前预测、实验过程记录与实验后解释进行对应，才能分析学生观念变化及其证据基础。 [Sources] v4 第31—33页 旧版报告第62—70页

证据层级与课堂观察

课堂证据需要联结任务、参与、证据与反馈，并限定解释层级

可复核的课堂证据
01

任务

教学目标转化为何种问题、材料与操作要求

02

参与

学生实际承担了哪些观察、比较、解释与协作

03

证据

哪些记录或话语支持对学习过程的判断

04

反馈

教师或系统的支持如何改变后续表现

课堂分析需要同时考虑任务要求、参与方式、证据质量和反馈作用。事实定位、结构分类与意义解释具有不同证据要求；系统可辅助完成前两类工作，学习意义仍需教师返回原始材料判断。 [Sources] 《第二章 AI赋能小学科学备课与课堂分析》：课堂观察与证据分析 旧版报告第65页

备课意图与课堂证据

教学改进来源于预设意图与实际证据之间的差距

备课意图课堂证据改进诊断

预设学生比较不同方案

→

课堂中主要执行教师指定步骤

→任务选择空间不足

预设学生依据数据解释

→

汇报集中于结果数值

→证据与主张的联系未被要求

预设支架促进独立完成

→

撤除提示后仍依赖固定句式

→支架尚未转化为方法

差距分析用于修订任务与支架，不用于追求教学流程与预案完全一致。

课后分析应将备课时的教学意图与课堂中的实际证据进行对照。差距可能来自任务设计、时间分配、材料限制或支架强度，需要进一步解释而不能直接归因于教师或学生。 [Sources] 《第二章 AI赋能小学科学备课与课堂分析》：备课意图与课堂证据对照

最小可行数据采集

课堂分析只需收集能够回答单一教学问题的必要证据

1界定一个教学问题
2保留学生初始作品
3截取关键课堂片段
4收集修订后作品

完整录制整节课不是课堂分析的必要前提。

课堂分析不必以完整录制为前提。围绕一个明确教学问题，保留初始作品、关键课堂片段和修订作品，已经能够形成基本的前后对照，并降低数据处理负担。 [Sources] 《第二章 AI赋能小学科学备课与课堂分析》：最小可行数据采集部分

观念变化分析

学生观念变化应依据预测、证据与解释修订进行分析

初始预测引发认知冲突的证据解释修订的具体内容新情境中的迁移表现
观念变化分析需要能够对应初始预测、关键证据、解释修订与迁移表现的材料。缺乏这些过程证据时，AI与教师都无法可靠判断变化的原因。 [Sources] v4 第32页 旧版报告第62页

KNOWLEDGE NOTE

可撤除性属于支架设计的基本条件

可撤除性是指技术支持能够随学习者独立能力的发展而降低，并最终由学生在弱支架或无支架条件下完成相近任务。

课堂意义

教学设计需要同时规定介入条件与退出条件。只有进入规则而没有退出规则，容易形成持续依赖。

判断依据

撤除时机应依据学生能否独立提出问题、比较证据和修订解释，而不宜依据固定课时或系统使用次数。

证据边界

使用过程顺畅不能证明支架有效；撤除后的独立表现与迁移表现才构成较强证据。

资料来源
《AI赋能小学科学——人机协同，素养共生》及本项目支架撤除框架。

KNOWLEDGE NOTE

表征迁移检验学生能否脱离单一资源形成解释

表征迁移是指学生能够在动画、模拟、实体模型、图示或文字之间转换，并保持对关键关系的一致解释。

判断对象

检验重点不是学生能否复述动画内容，而是能否利用另一种表征重新说明条件、机制与证据。

任务示例

日食动画结束后，学生用实体模型重建观察者、月球与太阳的位置关系，并解释何时不会出现日食。

证据边界

资源观看完成度与界面操作熟练度不能单独证明概念理解。

资料来源
v4 第17页；本报告对独立解释与迁移检验的操作化说明。

KNOWLEDGE NOTE

认知责任体现学生对知识主张的证据义务

在科学探究中，认知责任指学习者需要对问题形成、证据选择、解释建立与结论修订承担可辨识的思考责任。

课堂意义

学生完成操作并不等同于承担探究。需要进一步判断问题、证据和解释由谁形成。

观察线索

可以考察学生能否说明变量设置的理由、识别反例，并根据新证据修订原有解释。

技术边界

系统若同时生成问题、方案和结论，会压缩学生作出证据判断的空间。

KNOWLEDGE NOTE

有效探究机会需要同时具备任务、证据与认知责任

探究机会增量不是活动次数的增加，而是学生获得了原本难以实施的观察、变量比较、证据解释或论证修订机会。

可观察指标

可以比较技术介入前后学生完成的变量操作次数、证据类型、解释修订与独立迁移任务。

反例

系统生成更多问题、课件或答案，只能说明材料产出增加，不能说明学生承担了更多探究。

评价边界

机会增加仍不等同于学习效果；效果判断需要学生作品、迁移表现与适当研究设计。

观察结果与概念解释需要通过证据加以区分

先保存学生对‘消失’的初始解释，再决定需要补充何种证据。

实验推进

系统可定位遗漏条件，但不能替代学生形成初始方案或判断实验记录的可信度。

KNOWLEDGE NOTE

工程作品的实测差异来自参数与制造过程的共同作用

计算参数描述设计的理想几何关系，实测表现还受到折叠精度、边缘密封、材料形变与加载方式的影响。

课堂意义

工程学习不能止于计算最优参数，还需要通过制造和测试分析理想模型与现实结果之间的偏差。

证据要求

至少保留设计图、尺寸记录、作品照片、加载过程与失效位置，才能解释差异来源。

结论边界

单轮最高值不能直接转化为普遍最优设计，也不能据此评价学生的稳定能力。

最大承载量描述特定测试条件下的极限表现；安全承载量还要考虑扰动、材料差异、重复使用与失效后果。

课堂意义

教学处理

可以比较均匀加载、偏载和轻微扰动下的表现，再讨论合理的安全裕度。

证据边界

本案例用于建立工程安全判断，不提供可直接用于现实载具设计的工程参数。

KNOWLEDGE NOTE

课堂证据的三个解释层级

AI对课堂材料的处理，可以由低解释度的事实识别逐步进入高解释度的意义判断。层级提高并不意味着结论自动更可靠。

课堂意义

事实识别主要回答‘发生了什么’；结构分类回答‘呈现何种模式’；意义解释才涉及学生是否理解及教学产生何种影响。

证据边界

发言次数不能直接代表参与质量，关键词出现不能直接证明概念理解。意义判断应返回原始课堂片段、学生作品与教学目标核验。

系统功能

具备转写与检索能力的系统可定位片段和形成初步分类；教师需要返回原始语境、学生作品与实验记录复核。

资料来源
《第二章 AI赋能小学科学备课与课堂分析》：课堂证据分析；旧版报告第65页。

KNOWLEDGE NOTE

最小可行数据采集以教学问题为边界

最小可行数据采集不是尽量少收集材料，而是只保留能够支持特定教学判断且可以完成核验的必要证据。

设计原则

先确定需要回答的问题，再决定采集时间点、材料类型与保留范围。

可行方案

一份初始作品、一个关键片段和一份修订作品，常常比整节课的无差别录制更便于分析。

数据边界

采集范围越大，隐私、存储与误用风险越高；不需要的数据不应进入系统。

资料来源
书稿中的课堂分析数据采集建议及本报告的数据最小必要原则。

KNOWLEDGE NOTE

连续证据用于限定教学判断的范围

连续证据是同一学习目标在不同时间或不同任务中的多次表现，用于检验某项表现是否稳定并识别尚未出现的关键行为。

判断方式

多次使用数据支持主张，可以支持对该具体行为的暂时判断，但不能推断学生已具备完整论证能力。

后续任务

缺少回应反例的证据时，应安排具有替代解释或相反数据的新任务，而不是直接形成能力标签。

适用边界

连续证据提高了教学判断的可复核性，但仍受任务难度、提示强度与材料差异影响。

资料来源
v8方案文档：形成性评价与学习证据示例。

KNOWLEDGE NOTE

CER中的推理需要说明证据为何支持主张

CER由主张、证据和推理构成。推理部分需要说明证据与主张之间的逻辑关系，并指出适用条件与替代解释。

任务区分

科学解释说明现象机制；科学论证比较观点、限定主张并回应反例。二者均需证据，但任务功能不同。

常见问题

将实验结果再次抄写为推理，或只使用‘因为所以’句式，并未建立证据与主张之间的关系。

框架边界

CER是论证支架，不等同于完整科学探究过程，也不能保证结论正确。

资料来源
本报告对Claim–Evidence–Reasoning框架的教学化说明。

KNOWLEDGE NOTE

专业责任不能因系统参与而转移

教师可以使用系统输出作为信息线索，但实验安全、证据解释、学生支持与教学处置仍需由具有情境知识和制度责任的教师决定。

安全责任

器材、材料、操作步骤与突发情况需要依据真实课堂条件判断，不能仅依赖通用生成结果。

解释责任

课堂片段、学生作品与长期观察需要结合课程目标和具体语境解释。

处置边界

系统不得依据单次表现自动形成能力标签、分组决定或惩戒建议。

资料来源
CODEX_HANDOFF.md；v4 第42页；书稿中的教师专业判断边界。

KNOWLEDGE NOTE

教学智能体需要嵌入教师主导的证据循环

备课、实施、分析与改进由课堂证据持续连接；教学智能体只是在明确任务、输入、功能和输出边界后的限定配置。

循环关系

备课形成可检验意图，实施产生过程证据，分析解释差距，改进形成下一轮方案。

配置示例

食盐案例中，系统只读取去标识化的初始方案，每轮定位一个变量或证据缺口，不生成完整方案与结论。

适用边界

配置只能约束行为倾向，不能保证每次输出符合要求；正常、证据不足、概念错误与越界请求均需测试。

资料来源
《第二章 AI赋能小学科学备课与课堂分析》：教师主导教学循环与教学智能体配置。

KNOWLEDGE NOTE

数据最小必要原则同时限制采集范围与使用目的

仅收集完成明确教学任务所必需的数据，并限定保存期限、访问对象与后续用途。去标识化不能替代目的限制。

课堂应用

优先使用学生作品片段、匿名小组数据和局部课堂记录，避免无差别上传完整材料。

教师核验

使用前应确认学校制度、平台条款、账号权限和材料保存位置。

禁止推断

课堂数据不应被扩展用于人格、潜能、心理状态或稳定能力推断。

资料来源
书稿的数据治理部分及本报告的最小必要与去标识化原则。

KNOWLEDGE NOTE

决策审查用于把技术选择转化为可验证的教学假设

技术介入前应说明需要解决的教学问题、预期增加的学习机会、证据来源、教师复核方式与撤除后的检验任务。

介入强度

介入强度取决于系统替代的问题形成、变量选择、证据判断和解释修订等认知工作量。

复核要求

系统引用的证据需要能够返回原始作品、实验记录或可靠资料。

否决条件

无法说明必要性、数据边界或撤除条件时，应保留原有方案。

资料来源
v4 第44—45、52页；本报告的技术介入决策框架。
